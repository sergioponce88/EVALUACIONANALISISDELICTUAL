## Simulador de Evaluación – Análisis Delictual

Archivo: [`index.html`](index.html)

Simulador de examen multiple choice para la Licenciatura en Seguridad Pública (UNT):

- **Unidad 1** – Fundamentos y Política Criminal (30 preguntas)
- **Unidad 2** – Metodología y Objeto Criminológico (30 preguntas)
- **Unidad 3** – Estadística Moral y Positivismo (30 preguntas)
- **Simulacro General** – Examen integrador con las 90 preguntas mezcladas

Características:

- Navegación estrictamente unidireccional: cada respuesta queda bloqueada y no se puede volver atrás (también se bloquea el botón «Atrás» del navegador).
- Opciones mezcladas al azar en cada intento.
- Resultado final con criterio de aprobación ≥ 60 %, detalle de respuestas y descarga del acta en `.txt`.

Para usarlo, abrí `index.html` en el navegador o publicalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
